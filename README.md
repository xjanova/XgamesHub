# XgamesHub

Hubgame — รวมเกมไว้ในที่เดียว เล่นได้บนเบราว์เซอร์

## Tech stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## โครงสร้าง

- `src/app/` — หน้าเว็บ
- `src/data/games.ts` — รายการเกมในฮับ (เพิ่มเกมใหม่ได้ที่นี่)
