# BREAKER — สกิลตัวละครตามยศ

คอนเซปต์วันที่ 8 ตุลาคม 2026 · ยังไม่เพิ่มลงเดโม เป้าหมายคือปลดวิธีเล่นเพิ่มและเลือกบิลด์ได้ ไม่สะสมทุกสกิลพร้อมกัน

ยศความชำนาญแยกจากอันดับการแข่งขัน เลือกตัวละครประสานงานหนึ่งคนต่อรอบ ติดตั้งสกิลหลักหนึ่งและพรสวรรค์หนึ่งด้วยงบแต้มเท่ากัน ใน VS ทุกคนใช้ชุดมาตรฐาน การบริจาคไม่ปลดพลังพิเศษ มิร่าและโนวายังเป็นผู้สนับสนุนเร็นในเนื้อเรื่อง

## เร็น / นักชิงอาวุธ

เล่นใกล้อันตราย เปลี่ยนชิ้นส่วนเป็นจังหวะสวน

| ยศ | สกิล | วิธีเล่นและข้อแลกเปลี่ยน | แนวทางปลด |
|---|---|---|---|
| CADET / นักบินฝึกหัด | SALVAGE INSTINCT | เห็นจุดยึดที่กำลังจะแตกชัดขึ้น เลือกเปิดหรือปิดตัวช่วยได้ | จบบทฝึกชิงและดีดอุปกรณ์ |
| BRONZE / นักบินประจำการ | QUICK HAND | หลังยิงจุดยึดแตก เปิดหน้าต่างชิงเร็วหนึ่งครั้ง ต้องจับจังหวะให้ทัน | จบภารกิจ 3 รอบ พร้อมทำโจทย์ตัวละคร |
| SILVER / นักบินชำนาญการ | HOT RETURN | เลือกดีดของร้อนเป็นนัดหนัก หรือระบายกลับเป็นพลังงาน เลือกได้อย่างเดียว | ผ่านด่านต่างกัน 2 ธีม |
| GOLD / หัวหน้าหมู่บิน | CHAIN BREAK | ชิงแล้วดีดโดนจุดอ่อน ทำให้การชิงครั้งถัดไปต่อเนื่องขึ้น ไม่รีเซ็ตได้ไม่จำกัด | ผ่านแบบทดสอบการใช้สกิลประจำตัว |
| PLATINUM / ผู้นำฝูงบิน | FIELD PATCH | สละอุปกรณ์หนึ่งชิ้นเป็นเกราะชั่วคราวแทนการดีดโจมตี | จบชุดภารกิจด้วยบิลด์ต่างกัน 2 สาย |
| DIAMOND / นักบินชั้นยอด | COUNTER SALVAGE | หลบเฉียดที่นับได้แล้วดึงซากหนึ่งชิ้นเข้าระยะ แลกคูลดาวน์ของสกิลหลัก | ผ่านภารกิจท้าทายเฉพาะตัวละคร |
| ACE / ตำนานแห่งเคสเลอร์ | BREAKER'S OATH | เลือกท่า ACE: ดีดอุปกรณ์ทั้งชุดเป็นลูกโซ่ แล้วกลับมาสู้ด้วยช่องว่างทั้งหมด | ผ่านบททดสอบ ACE แบบเดี่ยว ไม่ต้องชนะผู้เล่นอื่น |

## มิร่า / ผู้บัญชาการสนาม

| ยศ | สกิล | วิธีเล่นและข้อแลกเปลี่ยน | แนวทางปลด |
|---|---|---|---|
| CADET / นักบินฝึกหัด | TACTICAL READ | สแกนศัตรูหนึ่งตัวให้เห็นจุดยึดและแนวยิงถัดไปช่วงสั้น | จบบทฝึกชิงและดีดอุปกรณ์ |
| BRONZE / นักบินประจำการ | SAFE VECTOR | เลือกแสดงเส้นช่องหลบล่วงหน้า หรือชี้เส้นทางเก็บอุปกรณ์ ไม่ใช่หลบให้อัตโนมัติ | จบภารกิจ 3 รอบ พร้อมทำโจทย์ตัวละคร |
| SILVER / นักบินชำนาญการ | DECOY PING | ส่งสัญญาณลวงให้ปืนติดตามหนึ่งกลุ่มเล็งผิดจุดช่วงสั้น | ผ่านด่านต่างกัน 2 ธีม |
| GOLD / หัวหน้าหมู่บิน | TARGET WINDOW | มาร์กจุดอ่อนเพื่อแสดงช่วงที่เปิดโจมตี แลกการหยุดสแกนเป้าหมายอื่น | ผ่านแบบทดสอบการใช้สกิลประจำตัว |
| PLATINUM / ผู้นำฝูงบิน | RESCUE ROUTE | เปิดตัวเลือกทางกู้ภัยพิเศษใน PvE ใช้เวลามากขึ้นแต่ได้โจทย์และเรื่องราวเพิ่ม | จบชุดภารกิจด้วยบิลด์ต่างกัน 2 สาย |
| DIAMOND / นักบินชั้นยอด | SIGNAL JAM | หน่วงการล็อกเป้าศัตรูในวงเล็ก ทำงานกับศัตรูที่ส่งสัญญาณเท่านั้น | ผ่านภารกิจท้าทายเฉพาะตัวละคร |
| ACE / ตำนานแห่งเคสเลอร์ | COMMAND OVERRIDE | เลือกท่า ACE: เปลี่ยนรีเลย์ศัตรูหนึ่งจุดให้ช่วยยิงชั่วคราว แลกปิดสแกนระหว่างใช้ | ผ่านบททดสอบ ACE แบบเดี่ยว ไม่ต้องชนะผู้เล่นอื่น |

| BRONZE / นักบินประจำการ | HEAT BANK | เลือกเก็บความร้อนส่วนหนึ่งในแบตสำรอง แลกการฟื้นพลังงานที่ช้าลง | จบภารกิจ 3 รอบ พร้อมทำโจทย์ตัวละคร |
| SILVER / นักบินชำนาญการ | ECHO ROUTINE | ยิงสำเนาหน่วงเวลาตามทิศเดิมหนึ่งชุด ใช้พลังงานเพิ่มและไม่ติดตามเป้า | ผ่านด่านต่างกัน 2 ธีม |
| GOLD / หัวหน้าหมู่บิน | POWER WEAVE | ย้ายพลังจากอุปกรณ์หนึ่งช่องไปอีกช่อง ชิ้นที่ถูกย้ายออกหยุดทำงานชั่วคราว | ผ่านแบบทดสอบการใช้สกิลประจำตัว |
| PLATINUM / ผู้นำฝูงบิน | PHASE BUFFER | กางวงกรองกระสุนธรรมดาจำนวนจำกัด แพ้เลเซอร์และท่าหนัก | จบชุดภารกิจด้วยบิลด์ต่างกัน 2 สาย |

## แผนสร้างต้นแบบ

1. สร้างฐาน Loadout แยก frame / crew / active / passive / point cost และ whitelist สำหรับ VS; เซฟเฉพาะตัวเลือกที่ปลดแล้ว
2. ทดลองเพียง REN: FIELD PATCH และ NOVA: HEAT BANK ก่อน ใช้ระบบพลังงาน ความร้อน และช่องอุปกรณ์เดิม
3. กำหนด trigger, cooldown, energy cost และเงื่อนไขยกเลิกต่อสกิล ใช้เหตุการณ์จริงในการปลดยศ และแสดงความคืบหน้า ไม่มีการซื้อยศ
4. ทดสอบ reset เมื่อเริ่มใหม่/ตาย/เปลี่ยนฉาก/ถอดสกิล ไม่ให้เกราะหรือความร้อนค้างข้ามรอบ จำกัดวัตถุและจำนวนกระสุน
5. เพิ่มสกิล ACE ทีละตัวหลังผ่านสมดุล ใช้ replay ตรวจการใช้สกิลและหลบเฉียดก่อนเปิดอันดับ

เกณฑ์ความสนุก: ผู้เล่นอ่านผลและราคาที่จ่ายออก เลือกสกิลยศต่ำแล้วยังผ่านด่านได้ และทุกสกิลมีข้อได้เปรียบเฉพาะสถานการณ์ ตัวเลขคูลดาวน์/แต้มต้องวัดจากการเล่นจริงจึงประกาศ
