## รุ่นขยายที่ใช้เป้า 150,000 บาท

1. ปรับเดโมเดิม 2–3 สัปดาห์: สอนชิงอาวุธ ความยาก เสียง/UI ทดสอบกับผู้เล่นก่อนเพิ่มเนื้อหา
2. SOLAR FORGE 4–6 สัปดาห์: โซนร้อน/เย็น, HEAT SINK, บอส HELIOS เปิดวาล์วทีละด้าน
3. ION REEF + EVENT HORIZON 6–10 สัปดาห์: พายุ/รีเลย์/ARC TETHER/TESLA HYDRA แล้วแรงดึงเฉพาะพื้นที่/GRAVITY ANCHOR/NEMESIS ARK
4. เชื่อมแคมเปญและทดสอบ 2–3 สัปดาห์: รวมประมาณ 20–30 นาที ปรับจอยและเครื่องหลายระดับ

ประมาณการรวม 14–22 สัปดาห์เมื่อผู้ดูแลงานหลักมี 15–25 ชั่วโมงต่อสัปดาห์ร่วมกับผู้ช่วย AI ต้องทบทวนจากต้นแบบจริง ไม่ใช่วันส่งที่รับประกัน งบแบ่งงานด่าน/ระบบ/บอส 60,000; ภาพ 35,000; เสียง/เรื่อง 20,000; QA 20,000; สำรอง/ดำเนินงาน 15,000 บาท

เกณฑ์รับงานแต่ละด่าน: เล่นผ่านจากเริ่มจนจบด้วยอุปกรณ์เดิมได้ ไม่มีการบังคับพึ่งของสุ่มชิ้นเดียว ทุกอันตรายมีสัญญาณเตือน มีทางหลบ ไม่มีการสลับแกนควบคุมโดยไม่คาดหมาย และยังอ่านกระสุนออกเมื่อเอฟเฟกต์มาก ทดสอบทั้งทางแยกและการตาย/เริ่มใหม่ เก็บเวลาเฟรมและจุดที่ผู้เล่นเสียชีวิตก่อนทำภาพขั้นสุดท้าย

โมเดลต้นแบบ: เลือกยานและสกิลตั้งต้นในโรงเก็บ → จุดพักเลือก 1 จาก 3 การ์ด → เลือกสายเฉพาะลำ → จบ/ตายแล้วรีเซ็ตบิลด์ของรอบนั้น ปลดถาวรเป็นทางเลือกและของตกแต่ง เปลี่ยนสายฟรี ไม่บังคับฟาร์มเพิ่มพลังเพื่อผ่านเกม สำหรับ VS เปิดตัวเลือกมาตรฐานและงบแต้มเท่ากัน

ต้นแบบแรกเลือก WRAITH: เก็บเพียงตำแหน่ง anchor และเงาล่อ ไม่ทำ global time rewind; ตรวจตำแหน่งปลายทางไม่ฝังในกำแพง/นอกกล้อง ยกเลิก anchor เมื่อเปลี่ยนฉาก กำหนดคูลดาวน์จากการใช้จริงและให้รีเพลย์เล่นซ้ำได้ตรงกัน

อาวุธทดลอง 6 ชิ้น: PRISM LANCE หักเลเซอร์ด้วยปริซึมหนึ่งจุด; SCRAP BOOMERANG ใบมีดกลับพร้อมซาก; STITCH MINES ทุ่นคู่สร้างแนวพลังงาน; ECHO BURST ยิงซ้ำทิศเดิมด้วยความหน่วง; GRAV NEEDLE ดัดวิถีทั้งสองฝ่ายในวงจำกัด; HEAT BLOOM ระบายความร้อนเป็นวงกระสุนแลกหยุดยิงหลัก เริ่มเพียง PRISM LANCE + SCRAP BOOMERANG ก่อน คงระบบ entity/pool เดิมและจำกัดจำนวนวัตถุ

## VS และอันดับ — แยกจากงบสามด่าน

1. **MIRROR FOUNDRY / Score Duel:** ด่านประมาณสามนาที ใช้ seed/ศัตรู/ของตก/แต้มจัดยานเดียวกัน แข่งเงารีเพลย์ที่ไม่มี collision
2. **WRECK CIRCUIT / Time Attack:** สามช่วงซากเรือ ทางลัดเสี่ยงกับทางอ้อมปลอดภัย เวลาต่ำสุดที่จบได้ชนะ ไม่ปนบอร์ดคะแนน
3. **RELAY RIFT / realtime 1v1:** แย่งพลังงานจากรีเลย์กลางสนาม ต้องประเมินต้นทุนเซิร์ฟเวอร์ matchmaking ความหน่วง และพฤติกรรมหลุดออกจากห้องก่อนกำหนดวันส่ง

อันดับแบ่ง `(rulesVersion, stageId, seed, difficulty, mode, loadoutRules)` มีบอร์ดรวม/เพื่อน/สัปดาห์ ตรวจความสมดุลก่อนตัดสินว่าจะจัดอันดับแยกยานเพิ่มเติม คะแนนเสนอ: โบนัสจบ + ทำลายจุดยึด + ชิงแล้วใช้อย่างมีผล + โบนัสต่อเนื่อง ให้รางวัลแต่ละเป้าหมายครั้งเดียว ป้องกันฟาร์มปล่อย/ชิงชิ้นเดิม ค่าตัวเลขต้องมาจาก telemetry/การทดสอบ ไม่ประกาศสูตรที่ยังไม่ทดสอบเป็นกติกาจริง

เดโมปัจจุบันเก็บ HI ในเครื่อง จึงยังเชื่อถือเป็นอันดับออนไลน์ไม่ได้ ก่อนเปิด ranked ต้องมี run ID ที่ออกโดยระบบกลาง, seed/rules ที่ตรึงตลอดรอบ, input replay บน simulation fixed timestep + seeded RNG, ตรวจเหตุการณ์/ผลฝั่งเซิร์ฟเวอร์, จำกัดอัตราส่ง และรับผลต่อ run ID ครั้งเดียว ใช้เวลาจากระบบกลางในการเลือก season/quest ไม่เชื่อคะแนนหรือนาฬิกาจากเบราว์เซอร์ แยก god mode, checkpoint practice, modified rules และ replay ที่ไม่ตรงเวอร์ชันออก เก็บเฉพาะชื่อแสดงผลที่ยินยอม; ไม่นำข้อมูลโอนเงินไปอยู่ในอันดับ

เกณฑ์ผ่านก่อนลงทุน realtime: replay seed/input เดียวกันได้ checksum สถานะตรงกันในเครื่องที่ทดสอบ; รอบทดสอบ/ส่งซ้ำ/แก้สกอร์ถูกปฏิเสธ; ลดแลคแล้วไม่ทำให้ผลแข่งขึ้นอยู่กับเฟรมเรต เมื่อทำ 1v1 ให้เซิร์ฟเวอร์ตัดสินการชน/คะแนน มีเวลาหมดอายุของห้องและผลเสมอ/ยกเลิกที่ชัดเจน

## เควสรายวัน สัปดาห์ เดือน

- รายวันเลือก 2 จาก 3: ชิงของต่างชนิด 2 แบบในหนึ่งรอบ, ทำลายจุดยึดรวม 6, จบหนึ่งภารกิจ เป้า 10–15 นาที
- รายสัปดาห์: จบด้วยยาน 2 ลำ, ชนะบอสรวม 3, ผ่านสนามสัปดาห์ในโหมดฝึกหรือ ranked เป้า 3–5 รอบ
- รายเดือน: ปฏิบัติการเรื่องสั้น 4 ตอน, ทดลอง 3 สาย, เป้าชุมชนเมื่อมี backend พร้อม
- เปลี่ยนงาน 05:00 Asia/Bangkok; สัปดาห์วันจันทร์ เดือนวันที่ 1 คำนวณ period ID กลางเพียงชุดเดียว ไม่ผูกกับ 30 วันคงที่
- รางวัลสี/ลาย/ตรา/บันทึกเรื่อง ไม่มีโบนัสพลัง ไม่มีโทษจากขาดวัน ไม่บังคับชนะ VS มีเก็บของตกแต่งย้อนหลัง
- ต้นแบบ offline ต้องระบุความคืบหน้าเฉพาะเครื่อง เควสออนไลน์ย้ายไป authoritative events, key `(player, quest, period)` รับรางวัลได้ครั้งเดียว ประมวลผล run ที่จบในช่วงเปลี่ยนวันตามเวลารับรองของ run อย่างสม่ำเสมอ ไม่เอาหลักฐาน offline มาเพิ่มอันดับ

## เครื่องมือและการแบ่งงานที่ทำต่อได้จริง

คงฐาน JavaScript/WebGL2 เดิมสำหรับเกม และ Next.js static export สำหรับเว็บ เพื่อไม่เสียเวลาแปลงเอนจิน ผู้ดูแลงานกำหนดกติกาและเล่นทดสอบ; ผู้ช่วยโค้ดรับงานเล็กที่มี input/output กับเกณฑ์รับงานชัดเจน เช่น WRAITH anchor หนึ่งสกิล หรือระบบ seed/replay หนึ่งชั้น แล้วให้คนทดสอบความสนุกก่อนเพิ่มเนื้อหา

- [Blender](https://www.blender.org/about/license/) เป็นซอฟต์แวร์เสรี ใช้สร้างยาน/ฉากแล้ว render เป็น sprite ตาม pipeline เดิม
- [Krita](https://docs.krita.org/en/KritaFAQ.html) ดาวน์โหลดใช้งานได้ฟรี ใช้วาด/เก็บรายละเอียด texture และ UI
- [Audacity](https://www.audacityteam.org/) ฟรีและโอเพนซอร์ส ใช้ตัดเสียงและปรับระดับ SFX
- ใช้ Git และเครื่องมือเบราว์เซอร์ที่มีอยู่ในการตรวจเวอร์ชัน/ประสิทธิภาพ ต้นแบบ replay/quest offline ไม่ต้องซื้อบริการเพิ่ม

ตรวจข้อมูลเครื่องมือจากเว็บไซต์เจ้าของเมื่อ 8 ตุลาคม 2026 บริการสร้างภาพ/เสียง/ผู้ช่วย AI และการรันเซิร์ฟเวอร์ออนไลน์อาจมีค่าใช้จ่าย ไม่เหมารวมว่าเครื่องมือทั้งโครงการฟรี ใช้เครื่องมือฟรีทำฐานได้ และกันงบเสริมตามการใช้งานจริง

## ภาพจริงและช่องทางรับสนับสนุน

แกลเลอรีจับจากเดโมเผยแพร่จริงวันที่ 7 ตุลาคม 2026: combat, convoy, narrows และ ARGUS บอสใช้ทางเข้าทดสอบ `?silent=1&play=6` เพื่อจับภาพเฟสบอส ไม่ได้ใช้ god mode ภาพอื่นจากการวิ่งเดโม ไม่มีการสร้างภาพแทน gameplay ตัดเฉพาะขอบดำ 153px ด้านซ้ายเป็นภาพ 1572×884 แล้วบีบอัด WebP; OG crop 1200×630 ตัวละคร/โมดูลคัดลอกแอสเซ็ตจากเกมเดิม

`src/data/fund.ts` แยก BREAKER จาก HIVE ชัดเจน เป้า 150,000 ยอดเริ่มต้น 0 ผู้สนับสนุน 0 ระดับ 100/300/1,000/3,000 และยอดกำหนดเอง ไม่สร้างยอดหรือชื่อผู้สนับสนุนสมมติ

**ยังไม่เปิดรับโอน:** รอเจ้าของส่งหมายเลขพร้อมเพย์และชื่อผู้รับสำหรับเผยแพร่ ไม่มี QR จนกว่ากำหนดบัญชีถูกต้องแล้ว เมื่อพร้อม ให้ใส่เฉพาะรายการ BREAKER ทดสอบ QR/ยอดด้วยแอปธนาคารโดยไม่ต้องโอน และตรวจชื่อผู้รับก่อนประกาศเปิด ยอดรวมอัปเดตด้วยคนหลังตรวจรายการโอน; QR ไม่ยืนยันว่าเงินเข้า การส่งสลิประบุชื่อ X-NOVA: BREAKER เพื่อไม่ปนโครงการ ตรวจสิทธิ์การแสดงชื่อก่อนลงรายชื่อ

เผยแพร่ผ่าน CI และ workflow เดิมของ GamesHub ซึ่งเว้น `/play/` ไว้ ไม่เปลี่ยนตัวเดโม ปุ่มแชร์ชี้ URL จริงของแคมเปญ แต่ URL นี้จะใช้งานสาธารณะหลัง merge/deploy เท่านั้น
