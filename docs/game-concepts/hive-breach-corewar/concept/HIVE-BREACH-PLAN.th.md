ภาพและสเปกละเอียดอยู่ใน `LYRA-TRIPO-GUIDE.th.md` ปืนพกแยกโมเดลจากร่าง เอฟเฟกต์ฮีลเป็นแสงพัลส์สี cyan จากวงเอวไปขอบกระโปรง ท่า A-pose เดิมใช้ขึ้นโมเดลร่างได้ Q/Overdrive ของลีรายังไม่ได้กำหนด

## การควบคุม

- WASD เคลื่อนที่ เมาส์เล็ง คลิกซ้ายยิง
- Q สกิลประจำคลาส, Space แดช, E ระเบิด/อุปกรณ์, R ใช้ Overdrive, คลิกขวารีโหลด
- F ใช้งานประตู/เครื่องปิดรัง, Tab แผนที่และสถานะ, Esc หยุดเกม
- Overdrive สะสมพลังจากการฆ่าศัตรู เมื่อครบ 100% กด R ระเบิดพลังตามคลาส ปืนรีโหลดอัตโนมัติเมื่อหมดแม็ก และคลิกขวาเพื่อรีโหลดก่อนหมดได้

## วงจรการเล่น

เลือกคลาส → เลือกอาวุธและความสามารถเริ่มต้น → เข้าสถานี → ยิงและเก็บพลัง → เลือกอัปเกรดระหว่างรอบ → ตัดสินใจปิดรังหรือฟาร์มต่อ → สู้บอส → กลับฐานและปลดล็อกทางเลือก

“รังสด” เป็นจุดขาย: เมื่อปิดได้จะลดแรงกดดันและเติมโล่ แต่จะหยุดการเกิดศัตรูและพลังจากรังนั้น หากยังเปิดอยู่ระดับอันตรายจะเพิ่มและปล่อยศัตรูพิเศษ ผลตอบแทนมีเพดานและเวลากดดัน เพื่อไม่ให้ยืนฟาร์มไม่จบ

## ตัวละคร 4 คลาส

| คลาส | บุคลิก/สี | Q | Passive | ตัวอย่างแนวอัปเกรด | ข้อแลกเปลี่ยน |
|---|---|---|---|---|---|
| Vanguard | ทหารโล่ สีส้ม | โล่ด้านหน้า 3 วินาที | เติมโล่บางส่วนเมื่อปิดรัง | โล่สะท้อนกระสุน หรือระเบิดคลื่นเมื่อหมด | ยืนแนวหน้าได้ แต่เคลื่อนที่ช้ากว่า |
| Specter | หน่วยจู่โจม สีม่วง | Phase Dash ทะลุศัตรู มีช่วงอมตะสั้น | โบนัสยิงจุดอ่อนหลังแดช | แดชทิ้งระเบิด หรือมีชาร์จสองครั้ง | ตัวบาง ต้องใช้จังหวะ |
| Engineer | วิศวกร สีฟ้า | วางป้อมอัตโนมัติ อายุจำกัด | เก็บกระสุนได้มากขึ้น | ป้อมสองกระบอก หรือยิงสายฟ้าเชื่อม | มีเพดานจำนวนป้อม ต้องเลือกจุดตั้ง |
| Biotech | แพทย์สนาม สีเขียว | คลื่นติดสปอร์ ชะลอศัตรู | เก็บตัวอย่างชีวภาพฟื้น HP เล็กน้อย | สปอร์แพร่ระหว่างศัตรู หรือระเบิดเมื่อครบสแต็ก | ฆ่าฝูงดี แต่ดาเมจทันทีน้อย |

ทุกคลาสถืออาวุธทั่วไปได้ ความต่างมาจาก Q, passive, ค่าสถานะ และการแปลงสกิล ใช้โครงมนุษย์และแอนิเมชันหลักร่วมกัน เปลี่ยนสี หมวก ปืน และกระเป๋า ไม่สร้างคนละชุดครบตั้งแต่ต้น

Overdrive ใช้เอฟเฟกต์เดิมมาเสริม: Vanguard ปล่อยคลื่นผลักและเติมโล่, Engineer เร่งป้อมและกระสุนสายฟ้า, Specter ลดคูลดาวน์แดชช่วงสั้น, Biotech กระตุ้นสปอร์ให้ระเบิด ช่วงเวลาหรือความแรงต้องทดลองจริง ภาพคอนเซปต์แสดง R เป็นไอคอนคลื่น ตัวเกมต้องใช้ไอคอนของคลาสนั้นและปิดปุ่มไว้เมื่อพลังไม่ถึง 100%

เดโม 6–8 สัปดาห์เริ่มจาก Vanguard และ Engineer เท่านั้น อีกสองคลาสเป็นขอบเขตหลังเดโมผ่าน ตัวเลขสกิลในตารางเป็นจุดตั้งต้นสำหรับทดลอง

## ระบบอัปเกรด

ระหว่างภารกิจ: XP ถึงเกณฑ์แล้วเกมหยุดให้เลือก 1 จาก 3 การ์ด มีอัปเกรดอาวุธ สกิล และเอาตัวรอด การ์ดระดับทั่วไปสะสมได้สูงสุด 3 ขั้น ส่วนการ์ดแปลงสกิลมีข้อกำหนดชัดเจน เลือกสายหนึ่งแล้วอีกสายถูกปิดเมื่อเป็นทางเลือกที่ขัดกัน

ตัวอย่าง Engineer: ป้อมพื้นฐาน → เลือกช่วงยิงหรืออายุป้อม → ที่ขั้น 3 เลือก Arc Turret ยิงสายฟ้าเชื่อม 3 เป้าหมาย หรือ Twin Turret ป้อมคู่ที่ยิงเบากว่า ต้องเห็นความต่างจริงทั้งภาพและวิธีเล่น ไม่ใช่เพิ่มดาเมจทุกใบ

ตัวอย่าง Vanguard: โล่พื้นฐาน → เพิ่มเวลา/ลดคูลดาวน์ → Aegis Burst ผลักฝูงเมื่อโล่หมด หรือ Reflect Guard สะท้อนกระสุนที่รับตรงหน้า

หลังภารกิจ: เครดิตปลดล็อกปืน คลาส และชุดเริ่มต้น เก็บเลเวล/ความชำนาญแยกตามคลาส การเพิ่มค่าสถานะถาวรมีเพดานเล็กและทดสอบความยากใหม่ ไม่ทำให้การฟาร์มเป็นเงื่อนไขผ่านด่าน

เดโมมี 12 การ์ด, 2 การแปลงสกิล, 3 ปืน: Plasma Rifle, Scattergun, Arc Gun ใช้กระสุนหลักชนิดเดียวในเดโมเพื่อทำ UI และบาลานซ์ได้ง่าย

## ภาพ 2.5D ที่ลดงานปั้นได้จริง

ใช้ Godot 4.x รุ่น stable ที่เลือกแล้วล็อกเวอร์ชัน กับ GDScript และระบบ 2D กล้องมุมเฉียงคงที่ ตัวเกมแสดงภาพที่เรนเดอร์ไว้ล่วงหน้า จึงดูมีมิติแบบ 3D แต่ไม่ต้องสร้างฉาก realtime 3D เต็มรูปแบบ

1. เริ่มจาก Kenney Space Station Kit นำส่วนฉากเข้า Blender แล้วจัดแสงและกล้อง orthographic ให้เหมือนกัน
2. เรนเดอร์เป็นภาพพื้น ผนัง ประตู ลัง และท่อแบบแยกชิ้น พื้นใช้ซ้ำและเปลี่ยนตำแหน่งได้ ไม่เรนเดอร์ฉากทุกด่านเป็นภาพใหญ่ภาพเดียว
3. มนุษย์ต้นแบบ 1 โครง และเอเลี่ยนต้นแบบ 1–2 โครง มาจากแอสเซ็ตที่มีใบอนุญาตชัดเจนหรือโมเดลง่ายที่สร้างเอง บอสใช้โครงใหญ่/ชิ้นส่วนของต้นแบบแล้วเพิ่มแอนิเมชันเฉพาะ
4. ทำแอนิเมชันร่วมและใช้สคริปต์ Blender เรนเดอร์ 8 ทิศ ไม่วาดเฟรมการเคลื่อนไหวใหม่ด้วย AI ทีละภาพ
5. ใส่เงารูปวงรีใต้เท้า แสงกระบอกปืน รอยกระแทก ควัน และอนุภาคใน Godot ทำให้ภาพตอบสนองขณะเล่น

ข้อดี: ไม่ต้องทำผิวและรายละเอียดที่ผู้เล่นมองไม่เห็น ไม่ต้องทำ LOD หรือระบบกล้องหมุน โมเดลต้นแบบหนึ่งชุดผลิตภาพหลายคลาสได้

ข้อจำกัด: ไม่หมุนกล้อง ไม่มีการขึ้นลงหลายชั้นในเดโม แสงที่อบไว้ในสไปรต์เปลี่ยนไม่ได้เหมือน 3D จริง แสงเสริมใน Godot ต้องทำให้นุ่มและใช้ทิศทางสอดคล้องกับแสงฐาน มุมเฉียงยังต้องแก้การบังกันและจุดชนอย่างระมัดระวัง

งบภาพขั้นต่ำต่อชุด: idle 4, walk 8, shoot 4, hit 2, death 8 เฟรม × 8 ทิศ = 208 เฟรม ขนาดทดลอง 128–256 พิกเซลต่อเฟรม เลือกจากขนาดที่เห็นจริงบนจอ แยก atlas ตามตัวละคร/แอนิเมชันและอัดขอบภาพ ไม่ยัดทุกชุดลงแผ่นเดียว การแยก torso/legs เพื่อเดินและเล็งคนละทิศต้องเพิ่มชุดภาพและตรวจ seam; ทดลองกับคนต้นแบบก่อนเรนเดอร์ทุกคลาส

ชิ้นฉาก MVP: พื้น 6 แบบ, ผนัง 4, ประตู 2, ลัง 3, ท่อ/เครื่องจักร 5, ชิ้นรัง 3 รวมประมาณ 23 ชิ้น เปลี่ยนแสง สี และการวางเพื่อสร้าง 3 ห้องที่ต่อกัน

## เอฟเฟกต์และความอ่านง่าย

ธีมสี: เหล็กเทาเข้ม พื้นอ่านง่าย แสงฐาน cyan กระสุนผู้เล่น orange/amber เอเลี่ยนมีจุดอ่อน magenta วงเตือนศัตรู red

- ปืน: flash 2–4 เฟรม, tracer, ปลอกกระสุน, recoil, impact flash และเสียงหลายชั้น
- ระเบิด: แสงวาบสั้น เศษชิ้นส่วน ควัน แหวน shockwave และสั่นจอที่ลด/ปิดได้
- สายฟ้า: เส้นเชื่อมเป้าหมายพร้อมแตกกิ่งเล็ก ใช้เอฟเฟกต์ชุดเดียวร่วมกับปืนและป้อม
- ศัตรูโดนยิงมีปฏิกิริยาเฉพาะจุด บอสมีจังหวะเปิดจุดอ่อนและวงเตือนก่อนพุ่ง
- glow ใช้ HDR 2D และ renderer ที่รองรับหลังพิสูจน์ด้วย art slice; ถ้าต้องรองรับเครื่องเก่า ใช้ sprite แสงแบบ additive และลดเอฟเฟกต์แทน
- แยก HUD เป็นชั้น UI ไม่ให้ bloom/การสั่นจอทำให้ข้อความอ่านยาก

ไม่เปิด PointLight2D ทุกกระสุน จำกัดแสงจริงที่มีพร้อมกัน เช่น 4 จุด จัดลำดับจากระเบิดและการยิงใกล้ผู้เล่น กระสุนที่เหลือใช้ภาพ glow ลด particle เมื่อเกินงบ และมีค่าความแรงเอฟเฟกต์ให้ปรับ

## ศัตรูและด่านเดโม

Crawler วิ่งประชิด, Spitter ยิงกรดมีวงเตือน, Charger หยุดเตรียมพุ่งแล้วชน, Brood Guard มีเกราะด้านหน้า เดโมใช้ 3 ประเภทแรก บอส Brood Core มี 2 เฟส: ปล่อยลูก/กวาดกรด → เปิดแกนและพุ่งโจมตี

ภารกิจ BIO-LAB 07: เริ่มใน hangar → เปิดประตู power room → ปิดรังรวม 3 จุด → สู้บอส → เข้าลิฟต์อพยพ มีจุดเกิดและเส้นทางกำหนดไว้ เปลี่ยน seed ของคลื่นและการ์ดเพื่อเล่นซ้ำได้

เริ่มทดสอบที่ 30 ศัตรูพร้อมกัน เพิ่มเป้าหมาย 60 เมื่อผ่าน ไม่สัญญาศัตรูหลายร้อยก่อนวัดงานจริง ทางเดินและห้องควรมีเส้นทางวนหลบมากกว่าทางตัน

## โครงสร้างงานที่ coding agents ทำได้

Godot: Player/Weapon/Enemy/Hive/WaveDirector เป็น scene แยกกัน ข้อมูลคลาส ปืน สกิล การ์ด และคลื่นเป็น Resource/JSON ที่ตรวจความถูกต้องได้ ระบบบันทึกมี version และ fallback เมื่อไฟล์เสีย

ใช้ CharacterBody2D และ Area2D สำหรับร่าง/พื้นที่ตรวจจับ ใช้ ray/shape sweep กับกระสุนเร็วเพื่อไม่ทะลุศัตรู การเรียงภาพอิงตำแหน่งเท้าและ y-sort แยกผนังหน้าหลัง เปิด fade เมื่อผนังบังผู้เล่น

หลีกเลี่ยงการหา path ให้ศัตรูทุกตัวทุกเฟรม: ขอเส้นทางตามช่วงเวลาและทยอยอัปเดต แยก steering ระยะใกล้ จำกัดแรงเบียดเพื่อไม่ให้ฝูงกองติดประตู Pool projectile/VFX และเก็บ spatial buckets เมื่อวัดแล้วจำเป็น

เส้นทางงานที่เสนอ:
- Codex: combat loop, อาวุธ/สกิล/อัปเกรด, ข้อมูล, save, performance instrumentation
- Claude Code: สคริปต์ render/atlas, scene tooling, UI integration, รีวิวโค้ดและรัน acceptance checks
- เจ้าของ: ทดลองความรู้สึกยิง เลือก art direction และรับงานตาม milestone

แบ่ง module และ branch/worktree ชัดเจน ใช้ผู้ดูแลคนเดียวต่อ shared file ในแต่ละช่วง Commit งานย่อยพร้อมบอกวิธีทดสอบ ส่ง handoff เป็นข้อเท็จจริงที่ตรวจได้ Roles สลับกันได้ ไม่มีข้อจำกัดว่าความสามารถของ agent หนึ่งทำได้เฉพาะงานนี้

ภาพคอนเซปต์ใช้กำหนดสี มุมกล้อง และ HUD ไม่ใช้ภาพเดียวเป็นฉากเล่นโดยตรง ศิลป์สุดท้ายยังต้องเรนเดอร์และปรับ ผู้ช่วยเขียนโค้ดช่วยผลิตสคริปต์/เครื่องมือได้ แต่ไม่ทำให้ quality ของโมเดล rig แอนิเมชันและเสียงผ่านอัตโนมัติ

## แผน 6–8 สัปดาห์

สมมติผู้ดูแลงาน 1 คน ทำประมาณ 20–30 ชั่วโมงต่อสัปดาห์ ใช้แอสเซ็ตที่มีอยู่และ coding agents งานรวมกรอบ 120–240 ชั่วโมง ไม่ใช่คำรับประกันวันส่ง; ถ้าต้องปั้นและ rig ทุกตัวเองต้องเพิ่มเวลา

| ช่วง | งาน | สิ่งที่ต้องส่ง/เกณฑ์ผ่าน |
|---|---|---|
| สัปดาห์ 1 | ห้องเทา, เดิน/เล็ง/ยิง/แดช, ปืนแรก, Crawler | เกมลอง 3 นาที ยิงโดน หลีกเลี่ยงได้ ตาย/เริ่มใหม่ครบ ไม่มีปัญหากระสุนทะลุ |
| สัปดาห์ 2 | art slice ห้องเดียว + คน/เอเลี่ยนต้นแบบ + pipeline 8 ทิศ | ดูภาพจริง 30 วินาที: มุม/ขนาด/แสงสอดคล้องกัน จุดเท้าไม่ลอย ศัตรูไม่ถูกผนังบังแบบผิด |
| สัปดาห์ 3 | ปืน 3 แบบ, ศัตรู 3 แบบ, Director/รัง | ภารกิจต้นแบบมีเส้นทางครบ ฝูงไม่ติดประตู เล่นซ้ำ 3 seed ได้ |
| สัปดาห์ 4 | 2 คลาส, 12 การ์ด, การแปลง 2 แบบ | สายโล่กับป้อมให้วิธีเล่นต่างกัน เลือกการ์ด/ข้อกำหนด/คูลดาวน์ทำงานจริง |
| สัปดาห์ 5 | บอส, 3 ห้อง, ชนะ/แพ้/ผลรอบ/save | เดโม 10–15 นาทีจบตั้งแต่เลือกคลาสถึงกลับฐานและโหลดเซฟได้ |
| สัปดาห์ 6 | HUD, เสียง, เอฟเฟกต์, settings, ทดสอบ | export Windows ที่ผู้อื่นเปิดเล่นได้พร้อมใบอนุญาตและ known issues |
| สัปดาห์ 7–8 | เวลาเผื่อ art/bug/performance/บาลานซ์ | ปรับตาม playtest ทำ build เดโมที่เชื่อถือได้ก่อนขยายคลาส |

หาก art slice สัปดาห์ 2 ไม่ผ่าน ให้แก้ pipeline และลดรายละเอียด ไม่เร่งสร้างทั้งเกมด้วยภาพที่ยังไม่เข้ากัน งานแรกที่มอบหมายเมื่อเริ่มสร้าง: graybox 1 ห้อง 1 ปืน 1 เอเลี่ยน 3 นาที พร้อม build ให้ลอง

หลังเดโม: เพิ่มอีก 2 คลาส, 3 ด่าน/biome, 8–10 ศัตรู, 3 บอส และเนื้อเรื่องวิทยุสั้นเป็นรุ่นเล็ก มีกรอบหลายเดือนที่ต้องประเมินใหม่จากอัตราผลิตของจริง โหมด co-op และออนไลน์ควรแยกเป็นโครงการถัดไปเพราะเปลี่ยนสถาปัตยกรรมและภาระทดสอบ

## เกณฑ์รับเดโม

1. ผู้เล่นทำภารกิจจบได้ครบเลือกคลาส → อัปเกรด → ปิดรัง → บอส → ผลรอบ; pause หยุด combat และเวลาภารกิจจริง
2. สกิล 2 คลาสและการแปลงมีพฤติกรรมต่างกัน ข้อกำหนดการ์ดไม่ขัดกับของที่มี ตายแล้วรีเซ็ตได้ถูกต้อง
3. เป้าหมาย 1080p 60 FPS เมื่อมี 60 ศัตรูและเอฟเฟกต์ปกติ ต้องกำหนดเครื่องอ้างอิงจากเครื่องที่จะเล่นจริงก่อนถือว่าผ่าน วัด frame time P95 ≤16.7ms หลังอุ่นเกม ไม่ใช้คำว่า “เครื่องกลาง” โดยไม่มีสเปก
4. เล่นต่อเนื่อง 20 นาทีหลายรอบไม่ crash และไม่สะสม projectile/VFX ที่หมดอายุ memory กลับใกล้ค่าตั้งต้นหลังรีสตาร์ตรอบ
5. ลด/ปิดสั่นจอ ปรับเสียงแยก SFX/BGM ปรับความแรงเอฟเฟกต์ และเห็นขอบโจมตีบนพื้นโดยไม่อาศัยสีเพียงอย่างเดียว
6. save/load คงข้อมูลปลดล็อก อ่านเซฟเก่า/เสียแล้วไม่ทำให้โปรแกรมล่ม มีรายการ asset source/license

## เครื่องมือฟรีและแหล่งจริง

ตรวจแหล่งทางการวันที่ 5 ตุลาคม 2026 เลือก stable และบันทึกเวอร์ชันก่อนเริ่มงาน

| เครื่องมือ/แหล่ง | ใช้ทำอะไร | เงื่อนไข |
|---|---|---|
| Godot | ระบบเกม 2D UI particles export Windows | MIT ฟรีรวมงานขาย ต้องแนบ notice/license ที่เกี่ยวข้อง |
| Blender | กล้อง/แสง rig render sprites และ batch rendering | โปรแกรมฟรี ผลงานที่สร้างใช้ได้ตามต้องการ; แอสเซ็ตที่นำเข้ายังมีใบอนุญาตของมัน |
| Krita | แต่งภาพ portrait icon UI texture | ดาวน์โหลดจากเว็บทางการฟรี สร้างงานขายได้ |
| Audacity | ผสม/ตัดเสียงปืน ambience และมาสเตอร์ | ตัวโปรแกรม desktop ฟรี สิทธิ์เสียงต้นทางต้องดูแยก |
| Kenney Space Station Kit | โมดูลฉากสถานี 3D นำมาเรนเดอร์ | หน้าแพ็กระบุ CC0 มีดาวน์โหลดฟรีแยกแพ็ก |
| Kenney Sci-fi Sounds | เสียง sci-fi ตั้งต้น | CC0; เลือกและผสมใหม่ให้เหมาะกับปืน |
| Kenney Particle Pack | texture ควัน แสง และอนุภาค | CC0 |
| Poly Haven | วัสดุ HDRI เพื่อ render ใน Blender | แอสเซ็ต CC0 ดาวน์โหลดขนาดพอเหมาะกับสไปรต์ |

งบ software/engine/แอสเซ็ตจากรายการนี้เริ่มได้ที่ 0 บาทบนคอมที่มีอยู่ ค่าใช้งาน AI, โควตาสร้างภาพ, hardware, ช่องทางขาย และบริการภายนอกเป็นค่าใช้จ่ายแยก ไม่ได้รวมอยู่ในคำว่าเครื่องมือพัฒนาเกมฟรี Pipeline ผลิตเกมไม่ต้องพึ่ง API สร้างภาพแบบจ่ายเงิน: ใช้ Blender/Krita/แอสเซ็ต CC0 ได้ครบ

ไม่จำเป็นต้องซื้อโปรแกรมทำ sprite atlas ตั้งแต่แรก ทำสคริปต์ pack PNG พร้อม metadata ของ pivot/frames เอง หรือใช้ SpriteFrames ของ Godot ตามขอบเขตจริง
