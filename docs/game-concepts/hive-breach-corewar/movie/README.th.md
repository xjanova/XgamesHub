# COREWAR — คัตซีนคอมมานเดอร์เอเลี่ยนเพิ่มเติม

เพิ่มภาพใหม่ 4 ช็อตด้วย built-in image_gen ใช้ภาพขึ้นชื่อเดิมเป็น reference เฉพาะใบหน้าและชุด แต่เปลี่ยนเป็นฉากบัญชาการกองทัพ ไม่มีตัวอักษรฝังบนภาพ

| ช็อต | ตัวละคร / เผ่า | เหตุการณ์ | ระยะเสนอ |
|---|---|---|---|
| 01 | KHAEL / MYRAX | สั่งฝูงบุกจากระเบียงชีวภาพท่ามกลางฝน | 5 วินาที |
| 02 | SAERYN / MYRAX | บัญชาการจาก Brood Heart พร้อมกองทัพที่รอคำสั่ง | 5 วินาที |
| 03 | VAEL / AETHERION | จัดแนว Sentinel ด้วยสัญญาณผลึกเฉพาะกองทัพในพื้นที่ | 5 วินาที |
| 04 | NYXARA / AETHERION | สั่งเปิดม่านพลังระหว่างเสา Nexus จากระเบียงป้อม | 5 วินาที |

รวม 20 วินาที เป็นระยะสำหรับตัดต่อที่เสนอ ไม่ใช่ความยาวคลิปที่สร้างแล้ว

## ใช้ทำ MV

1. เปิด index.html เพื่อดูภาพและคัดลอก Motion prompt ของแต่ละคน
2. ส่ง PNG ทีละภาพเป็นภาพตั้งต้นให้เครื่องมือ image-to-video ที่รองรับ พร้อม Motion prompt ใน image-and-motion-prompts.txt แนะนำการเคลื่อนไหวสั้นและเบาเพื่อรักษาหน้าและมือ
3. ตั้งไทม์ไลน์ 1920 × 1080 / 24 fps และปรับภาพ Fill ภาพต้นฉบับจริง 1672 × 941 (~16:9) ไม่ใช่ 4K
4. ใส่ commander-titles.srt เพื่ออ้างอิงชื่อและเวลา 0–20 วินาที แล้วจัดสไตล์เป็นชื่อใหญ่และบรรทัดเผ่า/COMMANDER เล็กกว่า SRT ไม่มีการกำหนดฟอนต์หรือตำแหน่ง
5. หากแทรกใน MV V4 ภาพชุดนี้อยู่ 59–79 วินาที หลังช็อตขึ้นชื่อเดิม ใช้ไฟล์ movie-titles-commander-cinematics.srt ของ V4 ซึ่งเลื่อนเวลาให้แล้ว

## ขอบเขตดีไซน์

- KHAEL / SAERYN คือรูปลักษณ์ชาย/หญิงของ MYRAX และ VAEL / NYXARA คือรูปลักษณ์ชาย/หญิงของ AETHERION ใช้ kit เผ่าเดิมสองเผ่า ฉายาในบอร์ดฉากไม่ได้สร้างอาชีพหรือสกิลใหม่
- เป็นคอมมานเดอร์ควบคุม RTS ในคัตซีน ไม่ได้เพิ่ม avatar ต่อสู้หรือโมเดลเดินลงสนามใน MVP
- การแสดงผลสัญญาณควบคุมเป็นพื้นที่ใกล้ตัว ไม่เปิดเผยแผนที่ทั้งหมดหรือศัตรูหลัง Fog of War
- ยานไกล ๆ ที่ปรากฏในช็อต NYXARA เป็นองค์ประกอบภาพยนตร์ของโลกเกม ไม่ใช่การรับรองยูนิตบินใน MVP
- ตรวจภาพจากผลลัพธ์ที่แสดงจริงครบ 4 ภาพและตรวจไฟล์ PNG แล้ว Gallery ตรวจโครงสร้าง/ลิงก์/ไวยากรณ์ แต่ยังไม่ได้ตรวจการแสดงผลในเบราว์เซอร์
- ชุดนี้มีภาพ พร้อมต์ และแผนตัดต่อ ยังไม่มีคลิปวิดีโอ เพลง เกมเพลย์จริง หรือโมเดล 3D
