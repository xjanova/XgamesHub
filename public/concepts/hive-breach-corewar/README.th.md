# HIVE // BREACH: COREWAR — เว็บอาร์ตแพ็ก

ไฟล์ในโฟลเดอร์นี้เป็นภาพคอนเซปต์ที่พร้อมนำไปทำหน้าเว็บ Gallery, game detail, character roster, faction cards และ MV showcase

## โฟลเดอร์

- `art/` — ภาพ UI, gameplay, ตัวละคร, สกิล, คริสตัล, เมนู, PvE/PvP และระบบบัญชีทั้งหมด 52 ภาพ
- `mv/cinematic/` — ภาพคัตซีนหลัก 10 ช็อต
- `mv/commander/` — ภาพ KHAEL, SAERYN, VAEL, NYXARA 4 ช็อต
- `mv/intro/` — ภาพขึ้นชื่อผู้พิทักษ์และคอมมานเดอร์ 12 ช็อต
- `mv/gameplay/` — ภาพ gameplay ผู้พิทักษ์และ RTS Fog of War 8 ช็อต

## URL ที่เว็บใช้

ทุกไฟล์อ้างอิงจาก root ของเว็บได้ เช่น:
